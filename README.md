# 🌐 网络故障排查工具箱 (Network Diagnostic Toolkit)

面向 IT 运维工程师和普通用户的轻量级 Windows 网络排障工具。采用 `.bat` + `PowerShell` 混合编写，无需安装任何第三方依赖（纯绿色运行）。

**痛点解决**：当客户或非技术同事报修网络故障时，他们通常“说不清、道不明”。本工具提供**“一键体检”**功能，引导他们双击运行并生成标准化的 HTML 诊断报告；同时保留**“专家菜单”**，供 IT 人员远程指导客户执行高级排障命令。

---

## ✨ 功能特性

### 📊 模式一：一键自动诊断（面向小白用户）
*   **自动分层探测**：从本机 IP、网关、DNS、目标端口到 HTTP 服务，自动按照 OSI 模型自下而上检测。
*   **智能根因判定**：找出“最低失败层”，将复杂现象转化为一句人话（如：“域名解析异常”、“本机到路由器连接不通”）。
*   **结构化报告**：自动在 `诊断报告/` 目录生成 `.html` 和 `.json` 报告。UI 区分“客户视角结论”与“工程师排查证据”。
*   **零配置开箱即用**：无 UI 黑框进度提示，执行完毕自动打开报告所在文件夹。

### 🛠️ 模式二：专业排障菜单（面向 IT 工程师）
提供交互式菜单，指导非技术人员输入目标并执行高级测试：
1.  **基础 Ping**：测基础连通性。
2.  **长 Ping**：发送 20 个包，测试丢包与延迟抖动。
3.  **Ping 大包**：发送 1472 字节不分片包，排查 **MTU 问题**（小包通大包断）。
4.  **Tracert**：路由追踪（限制 15 跳，防止死等）。
5.  **PathPing**：节点丢包率分析。
6.  **NSLookup**：默认 DNS 解析测试。
7.  **指定 DNS 测试**：绕过本地 DNS，验证是否遭到劫持或污染。
8.  **Telnet / TCPing**：精准探测目标 TCP 端口存活状态。
9.  **Curl 测试**：精准输出 HTTP 状态码（如 200、404、502）。
10. **刷新 DNS 缓存**：一键 `ipconfig /flushdns`。
11. **查询公网 IP**：调用 `cip.cc` 获取真实出口 IP 与运营商。

## 📂 目录结构

```text
网络诊断工具/
├── 网络诊断.bat          # 启动器（必须为 ANSI 编码）
├── diagnose.ps1          # 自动诊断核心脚本（必须为 UTF-8 with BOM 编码）
├── config.ini            # 配置文件（首次运行自动生成）
├── tcping.exe            # (可选) 用于 TCPing 测试，需自行下载放入
├── targets.txt           # (已废弃) 目标配置文件，已整合进 config.ini
└── 诊断报告/             # (自动生成) 存放 HTML 和 JSON 报告
```

## 🚀 快速开始

### 1. 下载与准备
克隆本仓库或下载 Release 压缩包并解压。如果你需要测试 TCP 端口连通性，请自行下载 `tcping.exe` 放到同目录下。（注：Telnet 端口测试已内置 PowerShell 替代方案，`tcping.exe` 仅为补充）。

### 2. ⚠️ 编码极其重要（必读）
由于工具包含中文并调用系统底层命令，请务必保证文件编码正确，否则会闪退或乱码：
*   `网络诊断.bat`：右键编辑，另存为 **ANSI / GBK** 编码。
*   `diagnose.ps1`：右键编辑，另存为 **UTF-8 with BOM** 编码。

### 3. 运行
双击 `网络诊断.bat`，根据黑框菜单提示输入数字或字母即可。

## ⚙️ 配置文件说明 (`config.ini`)

首次运行“一键诊断”时，会自动在根目录生成 `config.ini`。你可以使用任何文本编辑器（推荐 VS Code 或记事本）进行修改。

```ini
# 1. 公共 DNS 列表（用于与本机 DNS 进行对比测试，多个用英文逗号分隔）
PublicDns=223.5.5.5,114.114.114.114

# 2. 一键诊断测试目标（多个用英文逗号分隔）
# 支持格式：域名、IP、带端口（10.1.1.1:3389）、带协议（https://oa.com）
TestTargets=https://www.baidu.com, www.qq.com, 192.168.1.100:8080

# 3. 连通性测试超时设置（单位：毫秒）
PingTimeoutMs=1500
TcpTimeoutMs=3000

# 4. HTTP 网页请求超时设置（单位：秒）
HttpTimeoutSec=8
```
> **注**：你可以根据客户的网络状况，适当调大超时时间（如将 `PingTimeoutMs` 调整为 `3000`），防止网络慢被误判为断网。

## ❓ 常见问题 (FAQ)

**Q1: 双击闪退怎么办？**
A: 99% 是编码问题。请确保 `网络诊断.bat` 使用 ANSI 编码保存；其次，确认没有被杀毒软件（如 360、火绒等）拦截，可以尝试右键“以管理员身份运行”。

**Q2: 报告找不到？**
A: 报告默认保存在脚本同目录下的 `诊断报告` 文件夹中。如果脚本在只读目录（如 `C:\Program Files`），工具会自动回退并将报告保存在“桌面”上。

**Q3: 为什么公网 IP 定位不准？**
A: 脚本调用外部 API 获取归属地，如果显示“广州”但你实际在“重庆”，通常是因为运营商采用了 CGNAT 技术，统一从省级出口节点访问外网。**IP 地址真实有效，地理位置仅供参考。**

**Q4: 工具会修改电脑网络配置吗？**
A: 本工具遵循**纯只读**原则，所有测试均不会修改您的 IP、DNS、代理或路由表（菜单中的“刷新 DNS 缓存”除外，这是安全且无害的安全操作）。
